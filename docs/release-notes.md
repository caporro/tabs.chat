The first public beta of tabs.chat: a browser workspace for cloud and local AI models.

- Open https://tabs.chat or download one portable HTML file below.
- **Normal** includes Mermaid diagrams, math rendering and PDF/DOCX text extraction.
- **Lite** keeps chat, images, text/code attachments, notes and tools in a smaller file.
- Create agents with their own providers, instructions and tools, then share their configuration through a link.
- Use local or cloud models, built-in tools and compatible MCP servers.
- Thinking and temperature use server defaults in Auto. Reasoning display is independent of generation settings.
- Provider-specific output limits and a visible fallback for models without tool support improve compatibility.

No tabs.chat account is needed. Settings and conversations are saved in browser storage. AI requests go to the configured services; the optional proxy and web-fetch tool have their own external destinations, described in the documentation.

PWA installation is planned for a later release. Automated checks use local fixtures; live provider compatibility depends on the selected model, endpoint and browser CORS configuration.

Verify the downloaded HTML files against **SHA256SUMS**. Both editions include their third-party license notices.
